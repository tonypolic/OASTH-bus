# 🚌 ΟΣΕΘ / ΟΑΣΘ Live Bus Map (v19)

Διαδραστικός χάρτης παρακολούθησης των αστικών λεωφορείων Θεσσαλονίκης (**ΟΣΕΘ / ΟΑΣΘ**) σε πραγματικό χρόνο, με αξιοποίηση του επίσημου δημόσιου Telematics API του ΟΣΕΘ.

---

## ✨ Χαρακτηριστικά

- **📍 Ζωντανή Παρακολούθηση Οχημάτων:**
  - Εμφάνιση θέσης λεωφορείων σε πραγματικό χρόνο.
  - Δυναμικά περιστρεφόμενα βέλη κατεύθυνσης κίνησης ανάλογα με το bearing/πορεία του λεωφορείου.
  - Αναλυτικά στοιχεία σε popup (αριθμός οχήματος, κατεύθυνση, γραμμή, ταχύτητα, τελευταία ενημέρωση).

- **🚏 Διαδραστικές Στάσεις & Τηλεματική:**
  - Προβολή 3.500+ στάσεων σε όλο το πολεοδομικό συγκρότημα.
  - **Ανεξάρτητη προβολή στάσεων γραμμής:** Κατά την επιλογή γραμμής, οι στάσεις της παραμένουν πάντα ορατές και ευδιάκριτες, ακόμα και όταν απενεργοποιούνται οι γενικές στάσεις της πόλης από το πλήκτρο «Στάσεις: ON/OFF».
  - Κλικ σε στάση για live πίνακα αφίξεων (γραμμή, προορισμός, χρόνος σε λεπτά).
  - Κουμπί άμεσης επανενημέρωσης (refresh) εντός του popup της στάσης.

- **🗺️ Επιλογή Γραμμής & Προβολή «ΟΛΑ»:**
  - Επιλογή συγκεκριμένης γραμμής με σχεδίαση των γεωμετριών της διαδρομής (πολύχρωμα shapes ανά κατεύθυνση/headsign).
  - Λειτουργία **«ΟΛΑ»** για ταυτόχρονη παρακολούθηση όλων των ενεργών λεωφορείων της πόλης.
  - Φίλτρο **«Ενεργές μόνο»** για εμφάνιση μόνο των γραμμών με κινούμενα οχήματα.
  - Γρήγορη αναζήτηση γραμμής με πληκτρολόγηση (Search input).

- **⚡ Υψηλή Απόδοση (High Performance):**
  - **Canvas Rendering (`L.canvas` & `L.circleMarker`):** Ομαλό rendering χιλιάδων στάσεων στα 60 FPS χωρίς επιβάρυνση του DOM.
  - **Differential Updates:** Τα markers των λεωφορείων ενημερώνονται επιτόπου χωρίς flickering και χωρίς να κλείνουν τα ανοιχτά popups.
  - **Σειριοποίηση ανανεώσεων:** Αποφυγή αλληλοεπικαλυπτόμενων κλήσεων στο backend.

- **🛡️ Έξυπνο Caching & Προστασία API:**
  - Connection pooling μέσω `requests.adapters.HTTPAdapter` για ταχύτατη επαναχρησιμοποίηση TCP/HTTPS συνδέσεων.
  - Server-side caching πολλαπλών επιπέδων (γραμμές, στάσεις, info διαδρομής, ενεργές γραμμές).
  - Προστασία από **Cache Stampede** με thread locks.
  - Παράλληλη συλλογή δεδομένων με `ThreadPoolExecutor`.

- **📱 Σύγχρονο & Responsive UI:**
  - Πλήρως συμβατό με κινητά, tablets και desktop οθόνες.
  - Αποθήκευση προτιμήσεων χρήστη στο `localStorage` (τελευταία επιλεγμένη γραμμή, κατάσταση εμφάνισης στάσεων).
  - Ρυθμιζόμενος ρυθμός ανανέωσης (5s, 10s, 15s, 20s).

## 🛠️ Τεχνολογίες

- **Backend:** Python 3.10+, Flask, Requests
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+), Leaflet.js, OpenStreetMap
- **Data Source:** ΟΣΕΘ Telematics API (`https://oseth.com.gr/el/telematics-api`)

## 🚀 Εγκατάσταση & Εκτέλεση

### 1. Προαπαιτούμενα
Βεβαιωθείτε ότι έχετε εγκατεστημένη την **Python 3.10** ή νεότερη:
```bash
python --version
```

### 2. Εγκατάσταση Εξαρτήσεων
Εγκαταστήστε τις απαιτούμενες βιβλιοθήκες:
```bash
pip install flask requests
```
*(ή στα Windows: `py -m pip install flask requests`)*

### 3. Εκκίνηση της Εφαρμογής
Εκτελέστε το script:
```bash
python busmap_all_v19.py
```
*(ή στα Windows: `py busmap_all_v19.py`)*

### 4. Άνοιγμα στον Browser
Ανοίξτε το πρόγραμμα περιήγησης στη διεύθυνση:
```
http://127.0.0.1:5000
```

## 📡 API Endpoints

Η εφαρμογή παρέχει τα ακόλουθα εσωτερικά REST endpoints:

| Endpoint | Μέθοδος | Περιγραφή |
| :--- | :---: | :--- |
| `/` | `GET` | Το κύριο Web UI με τον διαδραστικό χάρτη Leaflet |
| `/api/routes` | `GET` | Επιστρέφει τη λίστα όλων των διαθέσιμων γραμμών |
| `/api/all-stops` | `GET` | Επιστρέφει όλες τις στάσεις του δικτύου (με 12h caching) |
| `/api/active-lines` | `GET` | Επιστρέφει τις γραμμές που έχουν ενεργά οχήματα |
| `/api/live` | `GET` | Επιστρέφει θέσεις οχημάτων. Παράμετροι: `line=<short_name>` (προαιρετικό) |
| `/api/arrivals` | `GET` | Επιστρέφει εκτιμώμενες αφίξεις σε στάση. Παράμετροι: `stop_id=<id>` |
